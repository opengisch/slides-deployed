COMMUNITY ZUERST

Now, if there’s one thing I want to be absolutely clear about today, it’s this: This project was started by a volunteer. It was grown by volunteers. From grassroots hackfests to full-blown conferences. From quiet pull requests to life-changing deployments. And that’s the secret: our strength is not just our code — it’s our community.

QT6

Umstieg auf Qt6, das moderne Applikationsframework, auf dem QGIS gebaut ist.
  • Sicherheitsverbesserungen
  • Moderne Codebasis mit vereinfachter Maintenance
  • Updates von Abhängigkeiten

QGIS 4.0

  • QGIS 4.0 wird ausschliesslich auf Basis von Qt6 sein
  • Es sind keine grösseren Anpassungen an der API vorgesehen
  • Die Arbeiten dafür laufen aktuell auf Hochtouren
  • Der LTR kommt mit QGIS 4.2, geplant für Anfang Mitte 2026
Das Ziel: den Umstieg so einfach und risikolos wie möglich zu machen.
This is a massive change — but we’re ready for it. And we’re making it as developer-friendly as possible.

WIE GEHT’S WEITER

Was kommt als nächstes?

Wir denken nicht nur an Patches und Features — wir denken an eine langfristige Strategie:
  • Eine einheitlichere Nutzererfahrung in der Dokumentation
  • Eine Sprache welche zu Entscheidungsträger in grossen Organisationen spricht
  • Sichere und moderne Pakete für alle Plattformen
  • Smartere build pipelines (mit einer möglichen Reduktion von Energieverbrauch)
  • Und einer Community welche offen, freundlich und global bleibt
